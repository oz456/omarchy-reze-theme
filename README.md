# 💣 Omarchy Reze Theme

> *"Are you sure you want to pull the pin?"*

A deadly, refined dark theme for [Omarchy Linux](https://omarchy.org/) inspired by Reze (The Bomb Devil) from *Chainsaw Man*. Built with **DHH-style conviction**: uncompromising pitch-black OLED depth (`#0A0A0C`), explosive crimson highlights (`#E63946`), and vivid twilight hues designed to make your setup look breathtaking.

![Preview](preview.png)

---

## 🎨 The Aesthetic

- **Pitch-Black Canvas (`#0A0A0C`)**: Pure OLED darkness that lets windows and text stand out with razor-sharp contrast.
- **Detonation Crimson (`#E63946`)**: The primary accent — vibrant, commanding, and focused.
- **Twilight Violet (`#9D4EDD`)**: Paired with crimson in a dynamic 45° spinning Hyprland border gradient.
- **Pure White Clarity (`#F5F5F7`)**: Pristine foreground typography tuned for extended code reading.

## 🚀 Installation

Install directly with the Omarchy CLI:

```bash
omarchy theme install https://github.com/oz456/omarchy-reze-theme
omarchy theme set reze
```
