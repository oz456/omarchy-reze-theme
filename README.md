# Omarchy Reze Theme

A custom Reze (Chainsaw Man) inspired theme for [Omarchy Linux](https://omarchy.org/).

## Previews
![Preview](preview.png)
![Lock Screen](preview-unlock.png)

## Installation

You can install this theme directly using the Omarchy CLI:

```bash
omarchy theme install https://github.com/oz456/omarchy-reze-theme
omarchy theme set reze
```
